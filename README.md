# Student Record Manager ⭐

A simple, interactive web application built with **HTML, CSS, and JavaScript** as part of the **Student Records: Filter, Sort & Analyze | LF 2026** challenge by μLearn Foundation.

The application allows users to search, filter, and sort student records while viewing dynamically updated statistics.

## ✨ Features

- **Student Records:** Displays student names, courses, and marks in a table.
- **Search:** Find students by name.
- **Filter:** Filter records by course or minimum marks.
- **Sort:** Arrange students alphabetically by name or by marks in ascending or descending order.
- **Live Statistics:** Calculate the total number of students, average marks, and topper.
- **Dynamic Updates:** Automatically refreshes the table and statistics when search, filters, or sorting options change.
- **Responsive Design:** Adapts the layout for smaller screens.

## 🛠️ Technologies Used
